## Archived (historical)

These describe the **retired local ComfyUI demo flow** (the Windows `*.cmd`
scripts and local `python main.py` server that were removed when the product
moved to Lovable Cloud). They are kept for their product/demo narrative and
talking points. Anything referencing local ports, `.cmd` launchers, or a local
Comfy renderer no longer applies — see the `archive/comfyui-fork` branch for that
historical setup.

- [`FRANK_CREATE_DEMO.md`](./FRANK_CREATE_DEMO.md) — demo runbook.
- [`FRANK_CREATE_CALL_DAY.md`](./FRANK_CREATE_CALL_DAY.md) — call-day checklist.
- [`OPEN_FOR_CLIFF.md`](./OPEN_FOR_CLIFF.md) — stakeholder ("Cliff") launch notes.
- [`legacy-tanstack-plan.md`](./legacy-tanstack-plan.md) — an earlier plan to build a
  TanStack Start backend. **Superseded** by the in-process `frank-create/server/frankApi.ts`
  Vite middleware, which is the backend the app actually uses.
